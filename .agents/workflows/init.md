# Initialization Sequence (MANDATORY — run before every task)

// turbo-all

1. Read `AGENTS.md` at the project root — absorb project overview, mandatory rules (dual theme, responsive, i18n), and skills catalog.

2. Read `ORCHESTRATOR_README.md` at the project root — absorb system directives, agent teams, and the full initialization routine.

3. Identify which Skills are relevant to the current task. Navigate to `.agents/Skills/` and read the relevant `SKILL.md` files **concurrently**.

4. Confirm readiness: proceed to execute the task applying all loaded context (AGENTS.md + ORCHESTRATOR_README.md + Skills).

> ⚠️ Do NOT skip any step. This sequence is non-negotiable.
